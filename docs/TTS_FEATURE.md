# TTS语音功能说明

## 概述

MaiBot现在支持在普通聊天模式和自动模式下发送TTS语音消息。这个功能可以让机器人在回复文字的同时，有概率发送语音消息，提升聊天体验。

## 功能特性

- **多模式支持**: 支持普通模式(normal)和自动模式(auto)下的TTS功能
- **可配置概率**: 可以分别设置不同模式下的TTS发送概率
- **智能文本处理**: 自动处理文本使其更适合TTS播报
- **非阻塞设计**: TTS功能不会影响正常的文字回复流程

## 配置说明

### 配置文件位置
- 主配置文件: `bot_config.toml`
- 配置模板: `template/bot_config_template.toml`

### 配置项

在 `[chat]` 部分添加以下配置：

```toml
[chat]
chat_mode = "auto"  # 聊天模式
auto_tts_probability = 0.3  # auto模式下发送TTS语音的概率（0.0-1.0）
normal_tts_probability = 0.1  # 普通模式下发送TTS语音的概率（0.0-1.0）
```

### 配置参数说明

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `auto_tts_probability` | float | 0.3 | auto模式下发送TTS语音的概率，范围0.0-1.0 |
| `normal_tts_probability` | float | 0.1 | 普通模式下发送TTS语音的概率，范围0.0-1.0 |

### 概率设置建议

- **0.0**: 完全禁用TTS功能
- **0.1-0.2**: 低频率TTS，偶尔发送语音
- **0.3-0.5**: 中等频率TTS，适中的语音发送频率
- **0.6-0.8**: 高频率TTS，经常发送语音
- **0.9-1.0**: 极高频率TTS，几乎每次回复都发送语音

## 工作原理

1. **触发条件**: 当机器人决定回复消息时，会根据当前聊天模式检查是否发送TTS
2. **概率判断**: 根据配置的概率值进行随机判断
3. **文本处理**: 对回复文本进行优化处理，使其更适合TTS播报
4. **语音发送**: 通过TTS插件发送语音消息

## 使用示例

### 普通模式配置
```toml
[chat]
chat_mode = "normal"
normal_tts_probability = 0.2  # 20%的概率发送TTS
```

### 自动模式配置
```toml
[chat]
chat_mode = "auto"
auto_tts_probability = 0.4  # 40%的概率发送TTS
```

### 禁用TTS功能
```toml
[chat]
auto_tts_probability = 0.0
normal_tts_probability = 0.0
```

## 注意事项

1. **依赖TTS插件**: 此功能需要TTS插件正常工作
2. **性能考虑**: 高频率的TTS可能会增加系统负载
3. **网络依赖**: TTS功能可能需要网络连接
4. **错误处理**: 如果TTS发送失败，不会影响正常的文字回复

## 故障排除

### TTS不工作
1. 检查配置文件中的概率设置
2. 确认TTS插件已正确安装和配置
3. 查看日志文件中的错误信息

### TTS频率过高/过低
- 调整配置文件中的概率值
- 建议从较低的概率开始测试

### 语音质量问题
- 检查TTS插件的配置
- 确认网络连接正常
